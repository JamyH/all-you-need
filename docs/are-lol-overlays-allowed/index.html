Are LoL overlays allowed? Vanguard, bans and Riot's rules

Before installing anything next to League, most players ask the same question: can this get my account banned? Here is what separates a normal overlay from a cheat – written by the developer of a LoL overlay, so read it with that in mind.

Short answer: overlays that only show what you could already see or look up, through Riot's official interfaces, are a common and long-standing kind of League app. Tools that tamper with the game or reveal hidden information get accounts banned. Only Riot decides, so no third-party tool – this one included – can give you a guarantee.

What gets League accounts banned

  • Reading or changing the game's memory – the basis of scripts, orbwalkers and map hacks.
  • Injecting code into the game process or hooking its rendering.
  • Automating inputs – dodging, combos or last hits done by software instead of you.
  • Modifying game files, for example skin changers.
  • Revealing hidden information such as enemy positions in the fog of war.

This is what Riot's anti-cheat Vanguard is built to catch. It protects the game process; a separate window that never touches that process is a different thing.

What Riot allows for third-party apps

Riot publishes policies for developers. The core idea: apps may help players understand the game, but must not create an unfair advantage. In practice that means no information the game deliberately hides from you – which is why tools are not allowed to track enemy cooldowns for you, and why augment win rates are not shown in game.

Why does the overlay need Borderless mode?

Because it is an ordinary window lying on top of the game. In exclusive Full Screen, Windows gives the screen to the game alone and nothing can be drawn over it. An overlay that worked in Full Screen would have to hook into the game – exactly the kind of thing that is not allowed. So: Settings → Video → Window Mode Borderless.
