Questions

The honest answers.

Can I get banned for using it?

All You Need never reads or changes the game's memory, injects nothing and sends no inputs. It uses Riot's official Live Client Data API, the League client API that rune and stats tools use, and small screenshots of what is already visible on your screen. Information Riot does not allow (enemy cooldown timers, augment win rates) is deliberately left out. It is not reviewed or approved by Riot, and no third-party tool can promise anything – but it only shows what you could already see or look up yourself.

Why does Windows show a SmartScreen warning?

The app is not code-signed yet, and new unsigned files get a reputation warning. Click More info → Run anyway. Each release lists its SHA-256 checksum, and the full source code is on GitHub.

Does it cost FPS?

It reads a few small screen regions about once per second, analyses them locally and draws a single lightweight panel.

Does it work in fullscreen?

Set League to Borderless or Windowed – no overlay can sit on top of exclusive fullscreen. Resolution and HUD scale are detected automatically.

Is it available in English?

The interface is in German for now; an English version is planned. The values are numbers and icons, so it is usable without German.
